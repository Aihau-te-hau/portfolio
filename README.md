## ⚙️ Installation

### Prérequis

Avant de commencer, assurez-vous d'avoir installé :

* [Node.js](https://nodejs.org/)
* npm

Vous pouvez vérifier les versions installées avec :

node -v
npm -v

---

### Cloner le projet

git clone https://github.com/VOTRE-USERNAME/VOTRE-REPOSITORY.git

Puis accéder au dossier :

cd VOTRE-REPOSITORY

---

### Installer les dépendances

npm install

---

### Lancer le projet en développement

npm run dev

Le projet sera ensuite accessible à l'adresse indiquée par Vite, généralement :

http://localhost:5173

---

## 🏗️ Build de production

Pour créer une version optimisée du portfolio :

npm run build

Pour prévisualiser le build :

npm run preview

## 📱 Responsive Design

Le portfolio est conçu pour s'adapter aux différentes tailles d'écran :

* 🖥️ Desktop
* 💻 Laptop
* 📱 Tablette
* 📱 Mobile

La navigation se transforme notamment en menu hamburger sur les petits écrans afin de conserver une expérience utilisateur claire et agréable.

---

## 🎨 Design

Le design du portfolio utilise une palette de couleurs inspirée d'un style élégant et sobre :

| Couleur   | Utilisation                   |
| --------- | ----------------------------- |
| `#162B36` | Fond principal                |
| `#EDD9A3` | Texte clair                   |
| `#C9A84C` | Éléments principaux / accents |
| `#A88428` | Accents secondaires           |

L'objectif est de conserver une identité visuelle cohérente tout au long du portfolio.

## ♿ Accessibilité

* Navigation mobile adaptée
